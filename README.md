# communeX

**communeX** is a feature-rich community interaction platform built with Django. It allows users to connect through real-time audio, video, and text communication within customizable public and private servers.

## Features

- 🔐 Create and manage **public** and **private servers**
- 💬 Set up **text, voice, and video channels** within servers
- 🧑‍🤝‍🧑 Send and manage **friend requests**
- ✨ Channel permissions for privacy and moderation
- 🔔 Real-time communication 
- 🛡️ User authentication and secure access control

## Getting Started

### Prerequisites
